Publier vers mon téléphone

Lit le classeur Excel, en extrait les chiffres, et les envoie sur votre page privée.
Rien n’est installé sur l’ordinateur : tout se passe dans cette page.

1Connexion à GitHub

À remplir une seule fois. Ces informations restent dans ce navigateur, sur cet ordinateur.

2Mot de passe de la page

Obligatoire. Les chiffres sont chiffrés avant d’être envoyés : sans ce mot de passe, la page ne montre rien, même si son adresse est connue. À saisir une fois sur l’ordinateur, une fois sur chaque téléphone.
Mot de passe mémorisé sur cet ordinateur.

3Publier les chiffres

Dans Excel : Données → Actualiser tout, puis Enregistrer. La publication lit ensuite le fichier sur le disque.
Sinon, méthode classique : cliquez ici ou déposez votre classeur .xlsx
Mettre un bouton dans Excel (à faire une seule fois)
Un simple lien, pas une macro : le classeur reste un .xlsx ordinaire, sans avertissement de sécurité. Dans Excel, choisissez une cellule libre du tableau de bord (ou Insertion → Formes pour un vrai bouton), puis Insertion → Lien → Adresse web et collez ceci :
Ensuite, la mise à jour tient en trois gestes sans quitter Excel : Actualiser tout → Ctrl+S → clic sur le bouton. La page s’ouvre et publie toute seule.
Installation de l’application (à faire une seule fois)
Envoie les fichiers de l’application dans le dépôt, puis active la page web. Sélectionnez le dossier application reçu avec ce fichier. Les données ne sont pas envoyées par cette étape : elles le sont par l’étape 3, chiffrées.
